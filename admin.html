Giới thiệu & chữ

Kết nối GitHub

Thiết lập một lần để đưa portfolio lên địa chỉ miễn phí không có chữ “chatgpt”. Những lần sau, bạn chỉnh nội dung tại đây rồi xuất bản.

  1. Tạo repository trippin, chọn Public và bật Add README. Tạo repository ↗
  2. Tạo mã truy cập giới hạn cho repository này, quyền Contents: Read and write. Tạo mã truy cập ↗
  3. Điền bên dưới và kết nối. Sau lần xuất bản đầu, bật GitHub Pages theo hướng dẫn hiện ra.

Mã chỉ được giữ trong phiên đang mở và gửi trực tiếp đến GitHub. Khi tải lại trang, bạn cần kết nối lại.

Chưa kết nối. Bạn vẫn có thể sửa và xem trước bản nháp.

Xuất bản nội dung

Bản đang xem trên thiết bị sẽ được ghi vào repository đã chọn. Bản lưu trên GitHub tồn tại giữa các thiết bị; website cần GitHub Pages để đưa thay đổi ra công khai.

Sao lưu bản nháp

Tải bản sao gồm nội dung và file mới tải lên, để chuyển sang thiết bị khác hoặc gửi tôi cập nhật bản hiện tại.
