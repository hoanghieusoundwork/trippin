# TRIPPIN — Music Producer

Portfolio tĩnh với bản công khai, trình nghe YouTube preview và trang chỉnh sửa nội dung.

## Bật website
GitHub Settings → Pages → Deploy from a branch → main → / (root) → Save.
Địa chỉ dự kiến: https://hoanghieusoundwork.github.io/trippin/

## Cập nhật nội dung
Mở admin.html trên website. Chỉnh sửa, xem trước và kết nối GitHub để xuất bản. Mã truy cập chỉ nhập tại trang quản trị; giới hạn trong repository trippin với Contents: Read and write. Không ghi token vào file hoặc commit.

Nội dung chính ở data/content.json. Giao diện sử dụng HTML/CSS/JavaScript, font và ảnh được lưu cùng website.
